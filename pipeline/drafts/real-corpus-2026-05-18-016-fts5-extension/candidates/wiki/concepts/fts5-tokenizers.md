# Fts5 Tokenizers

In the SQLite FTS5 extension, tokenizers define how raw text input is converted into searchable tokens. They are configured via the `tokenize` option on a virtual table or during module initialization. This process determines which characters form words, how punctuation is handled, and whether stemming or case folding occurs.

## Built-in Options

FTS5 provides several pre-configured tokenizer types:

- **unicode61**: The default tokenizer. It splits text based on Unicode 6.1 character boundaries, handling most languages and scripts while ignoring common punctuation marks like commas and periods.
- **ascii**: A simplified tokenizer designed for ASCII-only environments, splitting on whitespace and basic punctuation without complex Unicode normalization.
- **porter**: Applies Porter stemming to tokens after the initial split, reducing words to their root forms (e.g., "running" becomes "run"). This is useful for search recall but may reduce precision.
- **trigram**: Converts text into overlapping sequences of three characters (n-grams), which is often used for fuzzy matching or when exact word boundaries are less critical than character proximity.

## Custom Tokenizers

For advanced use cases, custom tokenizers can be registered using the C API function `fts5_tokenizer_v2`. This allows developers to implement domain-specific splitting logic, such as handling specific programming language keywords or proprietary formatting rules. When a custom tokenizer is registered, it must adhere to the FTS5 interface for accepting input text and returning tokenized output with optional properties like offsets and lemma values.

## Integration with Indexing

The chosen tokenizer directly influences the structure of the internal index segments (`%_data` and `%_idx`). Tokens generated by the tokenizer become the keys stored in these segment B-trees. The `fts5vocab` module relies on these tokens to calculate term frequencies and statistics, supporting query types like prefix matching (using `*`) and proximity searches.
