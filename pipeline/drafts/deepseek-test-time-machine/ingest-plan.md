# Ingest Plan

## Source Summary
- H. G. Wells’ 1895 science fiction novella, first published via Project Gutenberg.
- Introduces the concept of a “time machine” and popularised time travel in fiction.
- Set in the year 802,701 AD; humanity has split into the Eloi (above ground) and Morlocks (below ground).
- Themes: class division, social inequality, and dystopian future.
