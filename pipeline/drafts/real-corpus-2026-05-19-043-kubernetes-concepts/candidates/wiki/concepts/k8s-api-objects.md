# K8s Api Objects

Kubernetes API objects are the fundamental abstractions used to represent a cluster within the Kubernetes system. These objects facilitate declarative configuration and automation, allowing users to define the desired state of their infrastructure and services.

The documentation provides significant coverage on these API resources, which include core categories such as Workloads, Services, Configuration, and Storage. Understanding these objects is essential for managing containerized workloads and services effectively across a portable, extensible, open source platform.
