# Dom Compatibility Snapshot

The [[dom-legacy-and-removed-apis|DOM Standard’s historical section]] documents a **frozen compatibility snapshot** for all core DOM interfaces. It catalogues every removed feature—among them `MutationEvent`, `Entity`, and `DOMConfiguration`—and supplies detailed browser‑compatibility tables derived from MDN data. These snapshots preserve a record of the legacy API surface as it existed when features were dropped, providing an archival reference for compatibility without imposing any current implementation mandate.
