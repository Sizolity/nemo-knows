# Dom Legacy And Removed Apis

The DOM Standard maintains a historical chapter that catalogues every removed API. Entries include legacy items like `MutationEvent`, `Entity`, and `DOMConfiguration`, providing a permanent record of features that have been withdrawn from the platform. In the same chapter, frozen compatibility snapshots for all core interfaces are documented; these snapshots, elaborated in [[dom-compatibility-snapshot]], aggregate browser‑compatibility data from MDN and serve as a stable reference for long‑term legacy support.
