# Georgi Gerganov

```

Georgi Gerganov is the original creator of the [[llama-cpp]] inference library. He first released the project in March 2023 to enable large language model execution on consumer hardware.

The library was initially conceived to run Meta’s LLaMA models directly on a laptop CPU, demonstrating that practical local inference did not require a dedicated GPU server or a Python environment.

Since its launch, the project has evolved into a community effort under the ggml‑org organisation, but Gerganov’s foundational design continues to guide its dependency‑light, portable character.

Gerganov’s work has had broad downstream impact. [[llama-cpp]] now supports many model families and serves as the engine for tools like Ollama and LM Studio, establishing it as a cornerstone of the local LLM ecosystem.
